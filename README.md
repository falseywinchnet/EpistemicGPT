# Features unique to this model:

- A novel non-softmax normalizing method for attention that permits diffusive operators
- A novel activation function I call LELU that maps to the logistic probability regime
- K,Q normalization and constraints that take into account the roles, needs, and hardships of K
- A novel dropout regime that improves learning on all tasks and reduces memorization
- an optimized highway connection method TBD
- An optimized rope TBD
- An optimized loss regulizer based on modern cramer-roe bounds research over arbitrary problems

If I switch over the rope to a high-density high frequency concentrating rope format, strip out the attention dropout, reduce heads, 
I can get sub 2.0 losses within 140 iterations- extremely fast learning on short range problems, but it falls prey to distractor type problems inherently in the content.

This is an open solicitation for proposals to improve the RoPE mechanism.
